```java
    /**
     * Get positions by status.
     * @param status the position status to filter by (as string: "OPEN", "CLOSED", "STOPPED", "TARGET_HIT")
     * @return List of positions with the given status
     */
    public List<PositionResponse> getPositionsByStatus(String status) {
        // Convert string to uppercase for comparison
        String statusUpper = status.toUpperCase();
        List<PositionEntity> allPositions = positionRepository.findAll();
        return allPositions.stream()
                .filter(p -> statusUpper.equals(p.getStatus().toUpperCase()))
                .map(this::convertToResponse)
                .collect(Collectors.toList());
    }
```

**Why this approach:**
1. PositionController receives String from REST path: `/api/positions/status/{status}`
2. Service method converts to uppercase and compares against entity status field
3. Entity status is stored as uppercase ("OPEN", "CLOSED", "STOPPED", "TARGET_HIT")
4. No enum conversion needed in controller, clean string handling in service
5. Matches how entity status fields are actually stored
