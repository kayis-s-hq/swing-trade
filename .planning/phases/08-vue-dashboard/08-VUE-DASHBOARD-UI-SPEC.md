## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f9fafb` (light) / `#0f172a` (dark) | Background, page surfaces |
| Secondary (30%) | `#ffffff` (light) / `#1e293b` (dark) | Cards, sidebar, nav |
| Accent (10%) | `#6366f1` (indigo-500) | Primary buttons, active states, links |
| Destructive | `#dc2626` (error-600) | Delete/close actions, error states |
| Success | `#16a34a` (success-600) | Profit indicators, success states |
| Warning | `#d97706` (warning-600) | Warning states, stopped positions |

### Accent Reserved For:
- Primary CTA buttons (Generate Signals, Close Position)
- Router link active states
- Focus rings on interactive elements
- Indicators requiring high visibility

### Semantic Color Usage:
- **Success:** Profit positive (% or $), Open positions, Buy signals
- **Warning:** Stopped positions, Medium confidence signals
- **Error:** Profit negative, Closed positions, Sell signals, Error states

## Implementation Notes

### Dark Mode
- Default: Light mode
- Persistence: localStorage key `dark-mode`
- Toggle locations: Sidebar footer, Header top-right

### Responsive Breakpoints
- Mobile: < 640px (sm)
- Tablet: 640px - 1024px (sm/md)
- Desktop: > 1024px (md/xl)

### Component Patterns

**Cards:** `rounded-2xl border border-gray-200 bg-white dark:border-gray-800 dark:bg-white/[0.03]`

**Buttons:** `rounded-lg bg-indigo-600 px-4 py-2 text-sm font-medium text-white hover:bg-indigo-700`

**Table headers:** `px-4 py-3 text-left text-xs font-medium text-gray-500 uppercase`

**Status badges:** `inline-flex items-center rounded-full bg-{color}-50 px-2.5 py-0.5 text-xs font-medium text-{color}-600 dark:bg-{color}-500/15 dark:text-{color}-500`
